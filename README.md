# Market Trends & Customer Insights Analysis of Zudio

## Project Overview
This project analyzes Zudio's retail performance using Power BI.

## Objectives
- Analyze sales trends (2023–2026)
- Identify top-performing categories
- Understand customer behavior
- Compare city-wise performance
- Evaluate discount effectiveness

## Tools Used
- Power BI
- Excel
- GitHub

## Key Insights
- Women's category generated the highest revenue
- Metro cities contributed the most sales
- Discounts increased purchase volume
- Sales showed consistent year-over-year growth
